# Online Shop 🛍️ for Hackathon Phase 1

A comprehensive guide for deploying the Online shop ecommerce applicaton on EC2 instance in form of Docker container.

1. Fork an open source repository (https://github.com/iemafzalhassan/online_shop/tree/Hackathon)

Read and understand the requirement before proceed with the practical implementation.

2. Clone the fork to your local machine:

``` bash
git clone https://github.com/ernxmrx/online_shop.git
```

3. Create and switch to a new branch.

``` bash
git checkout -b dev [new branch name]
```

Note - Please make sure docker service is installed on linux server.

```bash
apt-get -y update [Update package list] 
apt-get -y upgrade [Upgrades installed packages without user confirmation]
apt-get -y install docker.io [To install docker]
```
Important: By default, Docker daemon is bind to the unix socket and by unix socket is owned by the docker user.
Append our user to the docker group(ro execute the docker related command) and refresh the docker group to reflect the changes.

``` bash
sudo usermod -aG docker $USER && newgrp docker 
```

4. Write a Dockerfile to create the customize docker image.
Below is the reference "docker build" command to create the docker image via Dockerfile.

``` bash
docker build -t online_com_site:latest .

docker build -f ./Dockerfile_MultiStage -t online_com_site:latest . [use this command in case using customize name of the Dockerfile]
```

5. Check the logs generated during image ceation to avoid any kind of failure or error.
verify the image with below commands incase has been created successfully.

```bash
docker images [to list docker image]
docker inspect imageid [to check the complete details ofdocker image]
```

6. Now, we need to create the docker container with the help of docker image.
Before proceed to create the docker container, create the docker volume(required to preserve the data generated by container) and also create the docker network in case want to run our docker container in user defined bridge network.

``` bash
docker volume create online_ecom_new [To create docker volume]
docker volume ls [lists the docker volume]
docker volume inspect online_ecom_new [Check the complete details of docker volume]

docker network create online_ecom_net [To create docker network]
docker network ls [List the available docker network]
docker network inspect online_ecom_net [Check the complete details of a network]
```

Below is the reference command to create a docker container:

```bash
docker run -d -p 3000:30000 -v online_ecom_new:/app/logs/ --network online_ecom_net --name online_shop(container-name) online_com_site:latest   [To create Docker container]
docker ps -a [List all container]
docker logs container-id [To check the logs]
docker exec -it container-id sh [Go inside docker container]
```

7. Add an inbound rule with custom TCP port "3000" in security group of EC2 instance to access the application UI.

```bash
URL - http://XX.YYYY.XXX.YYYY:3000/ [applicaton is accesssible through web browser, capture the artifacts]

```

8. Post performing these steps, stopped and removed the docker container and then deploy the application with docker compose tool.

First, install the docker compose tool on Linux machine with below command.

```bash
apt install docker-compose-v2 
```

9. Created a docker-compose YAMl file named "docker-compose-service.yaml" and ran the docker container using docker compose tool.

```bash
docker compose -f docker-compose-service.yaml up -d [To create a container]

docker compose -f docker-compose-service.yaml down [To stop the container]
```

I was able to deploy the application successfully with docker compose tool as backend container is showing in running and healty state and application is accessible through my local machine.
[All the snapshots are captured in a word document file]
